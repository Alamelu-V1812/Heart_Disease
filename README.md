# Heart Disease Prediction Using Machine Learning

## Project Description
This project is a Machine Learning-based system that predicts the presence of heart disease using patient health-related data.

The project uses classification algorithms to analyze the input features and predict the target outcome.

## Objective
The main objective of this project is to build a Machine Learning model that can predict heart disease based on the given health-related data.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Machine Learning Models Used
- Logistic Regression
- K-Nearest Neighbors (KNN)

## Project Workflow
1. Load the heart disease dataset.
2. Explore the dataset and target values.
3. Separate the input features and target variable.
4. Split the dataset into training and testing data.
5. Train the Logistic Regression model.
6. Make predictions on the test data.
7. Evaluate the model using classification metrics.
8. Visualize the confusion matrix.
9. Apply K-Nearest Neighbors (KNN).
10. Compare KNN performance using different values of K.

## Evaluation Metrics
The models are evaluated using:
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Dataset
The project uses a heart disease dataset stored as `heart.csv`.
The target column is used to indicate the prediction outcome.

## Project File
- `Heart_Disease.ipynb` – Contains the complete Python code, Machine Learning implementation, evaluation, and outputs.

## Conclusion
This project demonstrates how Machine Learning classification algorithms can be used to analyze heart disease data and make predictions. Logistic Regression and KNN are implemented and evaluated using different performance metrics.

## Note
This project is developed for educational and Machine Learning practice purposes. It is not intended to provide medical diagnosis or medical advice.
